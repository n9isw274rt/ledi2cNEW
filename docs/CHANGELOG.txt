【2.0.1】2026-09-26
--------------------------------------------------------------------------------
修复：
    - timer.c: TFD_TIMER_ABSTIME 写法错误改为相对模式（it_value 填时长）
    - effect.c: 删除冗余 effect_set_color（与 effect_set_target 重复）
    - effect.c/effect_fade.c: FADE 完成后切回 STATIC 并停 timerfd，避免空转
    - command.c: 删除 effect_set_color 调用、cmd_source 冗余判断、无用 stdlib.h
    - main.c: client 数据循环处理多行（为将来 EPOLLET 留余地）
    - i2c.c: 删除 i2c_write_bright 冗余判断
    - socket.c: 修正"丢一半"注释为"全丢"


【2.0.0】2026-09-26
--------------------------------------------------------------------------------
重构版本。核心目标：模块化、事件驱动、空闲零开销。

架构：
    - 拆分为 10 个模块（原 1 个大文件）
    - 插件式效果引擎（EffectOps + 表）
    - 命令查表（CmdEntry）
    - 事件驱动（epoll + timerfd + signalfd）
    - 多客户端长连接

性能：
    - I2C 合并写：10 次  1 次（快 10 倍）
    - 空闲 CPU：50 次/秒唤醒   0%
    - 静态色不重复写 I2C
    - timerfd 按需启停

功能：
    - 7 个效果全部参数化
    - RANDOM 重写（随机色相 + 渐变）
    - BREATH / PULSE 加 bmax
    - RAINBOW 与 FPS 解耦
    - 删除文件通道
    - 删除配置模块
    - 删除 SET: 命令
    - AUDIO: 简化（只解析 RGB）
    - source 简化为 mic / system
    - OFF 独立命令

协议：
    - 统一格式：命令名:参数:参数
    - RGB:R:G:B 兼容为 STATIC
    - SOURCE:off 不再支持

删除：
    - 文件命令通道（led_rgb.txt）
    - 配置读写（ledd_config.txt）
    - SET:base / SET:peak / SET:bright
    - AUDIO mode 1~4 处理
    - select + usleep 主循环
    - 100ms 文件轮询
    - off 时 2 秒 select 超时
